# Chat Room Socket

A real-time chat room application powered by sockets. This project is designed to enable users to communicate instantly in shared rooms.

## Features

- Real-time messaging between users
- Multiple chat rooms support
- Simple and easy-to-use interface

## Getting Started

### Prerequisites

- Node.js installed on your machine

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/sidsara/Chat-Room-Socket.git
   cd Chat-Room-Socket
   ```
2. Install dependencies:
   ```bash
   npm install
   ```

### Running the Application

Start the server:
```bash
npm start
```
By default, the server will run on `http://localhost:3000`. Open this address in your web browser and start chatting!

## Usage

- Open the application in your browser.
- Enter a username and choose (or create) a chat room.
- Start sending messages in real time with other connected users.
